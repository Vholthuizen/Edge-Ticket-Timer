# Ticket Timer voor TOPdesk

Versie 1.1.8 bevat kleine layoutverbeteringen.

## Aangepast

- Extra ruimte tussen Play / Pauze / Stop en Nieuwe timer.
- Meer ruimte tussen de knop Leeg en de timerlijst.
- De tekst `Los van de TOPdesk timer` is verwijderd bij Overige werkzaamheden.

## Installatie

1. Pak de ZIP uit.
2. Vervang alle bestanden in de extensiemap.
3. Ga naar edge://extensions.
4. Klik op Opnieuw laden.
5. Ververs TOPdesk met F5.
